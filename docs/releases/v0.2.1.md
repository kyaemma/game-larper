### LARPINNNGGG (now with favorites)

Game Larper v0.2.1 adds favorites and fixes a few rough edges from v0.2.0.

Star the games you fake most. Find them again without typing.

## What's new

- **Favorites.** Star any game and it shows up whenever the search box is empty, sorted by name with a count in the header. Typing a query still searches the whole catalogue, and starred results keep their star.
- **Several ways to star.** Use the star on a search row, the star next to the current session in the bottom dock, **Add to favorites** in the row context menu (right-click, the Menu key or Shift+F10), or **Ctrl+D** on the selected game. Each one toggles, so the same action removes a favorite.
- **Favorites follow the game, not its name.** They are saved by Discord application ID in `favorites.json` beside your config (`%LOCALAPPDATA%\GameLarper\` on Windows, `$XDG_DATA_HOME/GameLarper/` or `~/.local/share/GameLarper/` on Linux). If Discord renames a game, the favorite picks up the new name.

## Fixes and reliability

- **Games missing from Discord's list stay starred.** If the catalogue stops listing a favorite for a while, it is kept and shown dimmed as "Not in Discord's list right now". It cannot be played until it comes back, but you can still unstar it.
- **Favorites are never overwritten by mistake.** If `favorites.json` exists but cannot be read, Game Larper leaves it alone and refuses changes until it can be read again. A file that cannot be parsed is renamed to `favorites.json.bad-<timestamp>` and the list starts empty, with a warning in the debug console.
- **Long favorites lists keep artwork memory bounded.** Artwork is fetched for the top rows of the list. Further down, rows show artwork that is already loaded, or the logo.
- **Correct version metadata.** The Windows executable's file properties now report the real version (v0.2.0 still said `0.1.0.0`), and catalogue and artwork requests send `GameLarper/0.2.1` instead of `GameLarper/0.1`. Both now come from the Cargo package version.
- **Debug console** has a new `favorites` area for favorites activity and warnings.

## Downloads

### Windows 10/11 x64

Download `GameLarper-win-x64.zip`, extract it, and keep:

```text
GameLarper.exe
GameLarper.Runner.exe
LICENSE
```

together.

The binaries are currently unsigned, so Windows may show an unknown-publisher / SmartScreen warning.

### Linux x64

Download `GameLarper-linux-x64.tar.gz`, extract it, and keep:

```text
game-larper
game-larper-runner
LICENSE
```

together. Run `./game-larper`.

Flatpak Discord remains unsupported and is not expected to detect host processes, because of sandboxing.

## Notes

Upgrading from v0.2.0 keeps your settings and queue. Favorites start empty.

Discord's game detector is undocumented, so some titles may not work on every client/platform combination.

The Linux archive is the portable build. For a per-user desktop entry and icon, build from source and run `cargo xtask install`.
