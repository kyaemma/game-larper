### LARPINNNGGG

Game Larper v0.2.0 is the first full Windows + Linux release.

Pick a game. Press play. Discord gets lied to.

## What's new

- **Linux support** with a native host/runner path, X11/XWayland handling, XDG paths, autostart, single-instance behavior, lifecycle hardening, and Linux CI.
- **Linux release package** with `game-larper` and `game-larper-runner` side by side.
- **Linux desktop installer** from source via `cargo xtask install`.
- **Live debug console** with structured levels, bounded history, subsystem tags, copy/clear/open-folder actions, panic logging, and path redaction.
- **Major RAM/artwork pass** with a bounded decoded-artwork cache, compact catalogue/runtime records, streaming catalogue parsing, shared HTTP agents, and lighter artwork validation.
- **Much faster search and UI work**: one-letter catalogue searches dropped from tens of milliseconds and hundreds of thousands of allocations to roughly 1 ms and a few dozen allocations in profiling.
- **UI/accessibility polish** including cleaner keyboard navigation, a compact About/Contributors section, platform-appropriate settings wording, and the animated Settings gear that follows the docked panel side.

## Downloads

### Windows 10/11 x64

Download `GameLarper-win-x64.zip`, extract it, and keep:

```text
GameLarper.exe
GameLarper.Runner.exe
LICENSE
```

together.

The binaries are currently unsigned, so Windows may show an unknown-publisher / SmartScreen warning.

### Linux x64

Download `GameLarper-linux-x64.tar.gz`, extract it, and keep:

```text
game-larper
game-larper-runner
LICENSE
```

together. Run `./game-larper`.

Native Discord detection has been manually verified on a contributor Linux setup. Exact behavior can still vary by display/session and Discord packaging; Flatpak Discord remains unsupported/expected not to detect host processes because of sandboxing.

## Notes

Discord's game detector is undocumented, so some titles may not work on every client/platform combination.

The Linux archive is the portable build. For a per-user desktop entry and icon, build from source and run `cargo xtask install`.
