# UI icons

Small monochrome icons for the Game Larper interface. Slint tints them at runtime, so every
file draws in plain white on a transparent background.

All icons were drawn for Game Larper, except `steam.svg`: the Steam mark from
[Simple Icons](https://simpleicons.org) 13.21.0 (CC0-1.0). Steam is a trademark of Valve
Corporation. The app only uses the mark to link a game to its Steam store page.

The official branding lives in `../branding/` and is not used from here.
